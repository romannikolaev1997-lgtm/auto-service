# Пятый цилиндр

Демонстрационный сайт автосервиса, созданный для портфолио. Проект показывает адаптивный интерфейс, анимации, доступную мобильную навигацию и локальную demo-форму записи.

## Стек

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion

## Возможности

- Адаптивная главная страница автосервиса.
- Каталог ключевых услуг и блок статистики.
- Навигация для desktop и mobile.
- Форма предварительной записи с локальной валидацией. Данные формы никуда не отправляются.
- Поддержка `prefers-reduced-motion` для основных анимаций.

## Локальный запуск

```bash
npm ci
npm run dev
```

Для production-проверки:

```bash
npm run build
npm run start
```

## Статус

Это demo-проект: бренд «Пятый цилиндр», контакты, адрес, показатели и тексты являются вымышленными и не описывают реальный бизнес. Ссылка на live demo будет добавлена при публикации.
